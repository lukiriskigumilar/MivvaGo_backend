# 🚧 MIVVA GO Ticket Booking Backend (Under Construction)

This project is a portfolio backend application for **MIVVA GO**, a fictional ticket booking company.

It is developed using the **Express.js** framework and aims to provide APIs for managing ticket bookings, user authentication, and other related features.

Currently, the project is **under construction**. Features and detailed documentation will be added progressively.
